## 二、A｜触屏控制验证（核心）
1. 进入游戏（朝阳谷口，初始场景）。
2. ✅ **见一个 GameHUD 虚拟摇杆**（应只有这一个，无双摇杆）——拖动摇杆角色能**走动/转向**。
3. ✅ 在**空白处滑动**（右半屏）能**旋转相机视角**。
4. ✅ **跳跃**、**跑步** 按钮（GameHUD 提供）生效。
5. ✅ **对话期锁移动**：打开任一对话/三选（如 P03 开场之问）时，角色**不乱跑**。
6. ✅ 全程**无 Lua error / 崩溃**。

> 若摇杆没出现 / 出现两个摇杆 / 摇杆不动：把启动日志（`已创建左上角调试触屏入口`）与有无 `[InputManager] 触摸输入已启用` 一并回传。

## 三、B｜P02 走近守桃老人（上轮被强制跳过的段）
1. 用摇杆走朝阳谷去**走近守桃老人**（白色交互点 `Int_oldman`）。
2. ✅ 走近触发**初见台词**（`[Flow] 走近交互 P02` + `远来的客人……`），播完 → 完成 P02 → 进 P03。
3. 确认日志：`[PlayerController] 拾取标记: oldman`。

## 四、C｜P11 采花 ×5（上轮被强制跳过的段）
1. 用摇杆满场找 **5 朵桃花**（`Blossom_wood/fire/earth/metal/water`）。
2. ✅ 每朵拾取触发**素女内心独白**（弹窗 + `[Flow] 拾取独白 <key>`），进度 `[Flow] 桃花进度 N/5`。
3. ✅ 集齐 5 朵 → `桃花进度 5/5` → 完成 P11 → 进 P12。
4. 确认日志：`[PlayerController] 拾取标记: <五行>`、`[Flow] 拾取独白 <五行>`、`[Flow] 桃花进度 N/5`。
