## 0. 风格基调（与《11-美术设定参考》一致）

> 国风水墨与写实融合、低饱和、暖光微冷、构图留白、桃花为主色（粉白）、山石青灰、复古质感、无文字无水印无现代物品。

## 1. 桃花（核心视觉元素）

**文字版可借鉴点（满山桃林）**：
- **构图**：远景漫山桃林 + 中景山谷层次，镜头由远及近推进；留白 1/3 以上，桃花林不铺满全幅。
- **配色**：粉白花瓣为主、嫩绿/青碧叶色为辅、山石青灰打底；低饱和，忌艳粉。
- **质感**：花瓣轻薄半透、边缘微卷；雾气氤氲，山体水墨皴擦感。
- **细节**：花瓣纷飞方向统一（随风）、少量花瓣落于水面/枝头特写。
- **提示词关键词**：`漫山桃花 云雾 山谷 远景 粉白 低饱和 水墨写实 留白 花瓣飘落`

## 2. 谷口 / 山谷 / 桃林场景

**文字版可借鉴点**：
- **构图**：谷口"收口"感——两侧山体向中间收拢，一条溪路/石径延伸向谷内；木屋半隐于桃林。
- **配色**：粉白桃花 + 青灰山石 + 竹绿点缀（谷内桃林更偏竹绿）；暖光从谷口方向射入。
- **质感**：山体水墨皴擦、木屋榫卯结构清晰、溪水留白反光。
- **细节**：谷口立一块素衣身影剪影（呼应素女守望位）；井、桃树群分布有致。
- **提示词关键词**：`山谷 谷口 溪流 榫卯木屋 桃林 青灰山石 水墨写实 暖光 留白`

## 3. 异域小镇 / 洛水阴山（S5、S6-4）

**文字版可借鉴点**：
- **构图**：街巷纵深透视，胡商摊位/驼队沿街分布；无面鬼蜷坐墙角为前景低机位。
- **配色**：暗褐建筑 + 雾青空气 + 残阳金（低饱和）；与朝阳谷的粉白形成冷暖对比。
- **质感**：土坯/夯土墙、粗粝石板路、驼铃金属微光、风沙雾霭。
- **细节**：异域纹样窗棂、挂毯、陶罐；**哀伤克制，不恐怖**——无面鬼靠体态与泪痕传达情绪。
- **提示词关键词**：`异域小镇 胡商 驼铃 残阳 雾霭 暗褐 低饱和 水墨写实 哀伤克制`

## 4. 服饰 / 角色（素女、无幽、守桃老人）

**文字版可借鉴点（素女·曲裾/襦裙）**：
- **制式**：交领右衽、宽袖、衣摆曳地；曲裾绕襟或襦裙配披帛。
- **配色**：素白为主、淡青/桃花粉点缀；无浓重刺绣（清雅）。
- **细节**：墨发挽髻插桃花簪；衣料轻薄垂坠（风吹衣袂轻扬）。
- **提示词关键词**：`素白曲裾汉服 交领右衽 墨发挽髻 桃花簪 衣袂轻扬 清雅`

**文字版可借鉴点（无幽·男装）**：
- **制式**：青灰布衣、交领、束袖（便于采药）；背旧药箱（竹木质感）。
- **细节**：发束高髻、眉眼温和；布衣有磨损补丁细节（行路之人）。
- **提示词关键词**：`青灰布衣汉服 束袖 旧药箱 发束高髻 眉眼温和`

**文字版可借鉴点（Q 版）**：
- 三头身、圆脸大眼、头身比夸张；服饰保留制式但简化褶皱；低饱和淡彩。

## 5. 器物 / UI 细节

**文字版可借鉴点**：
- **古琴**：伏羲式/仲尼式轮廓、琴弦细亮、琴身木纹；S6-2 琴弦落桃花瓣特写。
- **竹简**：竹片编绳、墨字竖排、微黄旧色；S6-5 灯下研方。
