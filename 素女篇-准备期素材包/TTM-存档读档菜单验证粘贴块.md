## 二、验证步骤
1. （可选）先清存档：删 `saves/slot1.json`，或在游戏内任意段进入后用「保存」覆盖。
2. ✅ **打开面板**：点右上「**菜单**」按钮 → 弹出居中「存档 / 读档」面板（含状态行 + 保存/读档/返回）。
3. ✅ **状态显示**：无存档时显示「暂无存档」；有则显示 `存档：段落 X @ Ys`。
4. ✅ **保存**：点「保存」→ 日志 `[SaveMenu] 已保存当前进度到 slot1` + `[PlayerData] 已保存到 saves/slot1.json`；状态行更新为当前段落。
5. ✅ **读档**：点「读档」→ 日志 `[SaveMenu] 已读档并续播` + `[Flow] 读档恢复：定位段落 …`，进入存档段落续播（视频中段则 Seek 双确认/降级续播）。
6. ✅ **返回**：点「返回」关面板；面板关闭后角色可正常移动。
7. ✅ **菜单锁移动**：面板打开时角色**不动**（含摇杆），关闭后恢复。
8. ✅ **持久化**：保存后**退出游戏重启** → 启动日志 `检测到本地存档，尝试自动续档` → 从该段落续播（验证磁盘持久化）。
9. ✅ 全程**无 Lua error / 崩溃**。

> 若菜单按钮点不到 / 面板不显示 / 保存读档无效：把启动日志与 `[SaveMenu]` 相关日志回传。
