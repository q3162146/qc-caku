# Physics Module (2D)

> **长度单位**: 米（meter）
> **重力加速度**: 米/秒²（如 `gravity = Vector2(0, -9.81)`）
> **速度**: 米/秒

`PhysicsWorld2D` · `RigidBody2D` · `CollisionShape2D` · `CollisionBox2D` · `CollisionCircle2D` · `CollisionEdge2D` · `CollisionChain2D` · `CollisionPolygon2D` · `Constraint2D` 等

详细 API 见 `.emmylua/PhysicsWorld2D.d.lua`、`.emmylua/RigidBody2D.d.lua`、`.emmylua/CollisionShape2D.d.lua` 等。
