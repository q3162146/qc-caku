## MouseButton

鼠标按钮枚举。**必须使用这些枚举值判断鼠标按钮，不要使用数字常量**。

```lua
MOUSEB_LEFT    -- 左键（不要用 0 代替！）
MOUSEB_MIDDLE  -- 中键
MOUSEB_RIGHT   -- 右键
```

**正确用法示例**：

```lua
function HandleMouseDown(eventType, eventData)
    local button = eventData["Button"]:GetInt()
    
    -- ✅ 正确：使用枚举值
    if button == MOUSEB_LEFT then
        -- 处理左键点击
    end
    
    -- ❌ 错误：使用数字常量
    -- if button == 0 then ...      -- 不要这样做！
    -- if button ~= 0 then return   -- 不要这样做！
end
```

## MouseMode

鼠标行为模式。详细使用说明请参考 [Input Module](input.md#鼠标模式设置指南)。

```lua
MM_ABSOLUTE   -- 默认模式，鼠标可自由移动（适用于菜单、RTS等）
MM_RELATIVE   -- 鼠标锁定+强制隐藏光标，获取相对移动量（适用于 FPS/TPS）
MM_WRAP       -- 鼠标到边界时环绕
MM_FREE       -- 鼠标不被限制，即使隐藏也不锁定
```
