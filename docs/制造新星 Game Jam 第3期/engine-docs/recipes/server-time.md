# 服务器时间（common.get_server_time）

> 🎮 **适用范围：客户端 Lua**
> 本接口适用于单机游戏的客户端，做限时活动判定、排行榜时间戳等需要**权威时间**的场景。
> 服务端 Lua 直接用 `os.time()` 即可——服务端进程的本地时钟由部署平台 NTP 同步，本身就是可信的权威时间。

同步获取**权威 Unix 秒时间戳**

## 何时用本接口 vs `os.time()`

| 场景 | 推荐 API | 原因 |
|---|---|---|
| 服务端 Lua 取任何时间 | `os.time()` | 服务端进程时钟由部署平台 NTP 同步，本身就权威 |
| 客户端 UI 显示当前时间 | `os.time()` | 玩家看到自己设备时间，符合预期；不涉及作弊 |
| 客户端：限时活动判定 / 冷却倒计时 / 排行榜时间戳 / 防作弊 | `common.get_server_time()` | 权威源 + 单调推算，**用户改系统时间无效** |

## 用法

```lua
local sec = common.get_server_time()
print("server time (sec):", sec)
```

## 转换为北京时间

时间戳不带时区，要显示成本地时间需自行换算。用 `os.date("!...")` 强制按 UTC 解析，避免叠加运行环境的本地时区：

```lua
local sec = common.get_server_time()
print("北京时间:", os.date("!%Y-%m-%d %H:%M:%S", sec + 8 * 3600))
-- 2026-04-28 17:35:33
```

## 返回值

| 项 | 类型 | 说明 |
|---|---|---|
| 返回值 | `integer` | Unix 秒时间戳（UTC 基准） |

## ⚠️ 注意事项

- **时区**：返回值是 UTC 秒，显示本地时区时间要自己偏移
