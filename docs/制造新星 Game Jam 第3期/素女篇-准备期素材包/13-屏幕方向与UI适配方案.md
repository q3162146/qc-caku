# 屏幕方向与 UI 适配方案（移动端横/竖屏 + PC）

> 结论先行：**以移动端竖屏（9:16）为主目标**，采用"固定逻辑分辨率 + 等比缩放 + 居中视口 + 环境背景层"一次性覆盖竖屏手机、横屏手机、平板与 PC，不做真正的双布局。

---

## 1. 平台矩阵与现状

| 运行端 | 分辨率/比例 | 交互方式 | 状态 |
|--------|-------------|----------|------|
| 移动端（Android/iOS） | 9:16 / 19.5:9 / 20:9 等 | 触屏（点击、滑动） | TapTap 主阵地，核心目标 |
| 平板 | 3:2 ~ 4:3 等 | 触屏 | 竖屏居中 + 环境背景 |
| PC（TapTap 客户端） | 16:9 / 16:10 / 21:9 | 键鼠 | 竖屏居中 + 环境背景 |
| 编辑器/网页预览 | 视窗口而定 | 键鼠 | 仅开发调试用 |

> ⚠️ 8/19 开工后第一件事：在编辑器内实测——TTM 新建项目的默认窗口方向、是否支持锁定竖屏、安全区 API、视频组件对 9:16 全屏的支持；真机预览（5 端）移到 9/4–9/5 打磨期（与《04-开发排期与合规清单》一致）。

---

## 2. 推荐方案 A：竖屏 9:16 为主

**逻辑分辨率**：1080 × 1920（9:16），按比例整体缩放。

**为什么选竖屏**：

| 维度 | 说明 |
|------|------|
| 演出契合 | Seedance 视频可原生生成 9:16 竖屏，全屏播放零裁剪，和短剧/短视频的观看习惯一致 |
| 叙事沉浸 | 竖屏全屏视频 + 底部字幕/选项，信息层级简单，专注剧情 |
| 传播热度 | 结局分享卡、名场面短视频都是 9:16 竖版，与短视频平台天然兼容，利于裂变 |
| 操作体验 | 单手可玩，拇指点按，对话选项纵向排列 |
| 开发量 | 只做一套 UI 布局，20 天赛程风险最低 |

**竖屏的代价与对策**：

| 代价 | 对策 |
|------|------|
| PC/横屏设备上中间一条竖屏 | 两侧用"环境背景层"填充：同场景放大模糊图或水墨装饰（UI 层绘制，不出黑边） |
| 3D 探索视野较窄 | 场景设计适配竖构图：路径纵向延伸、桃花树/望夫崖纵向取景，反而更有纵深 |

---

## 3. 备选方案 B：横屏 16:9 为主

仅在以下情况启用：

- TTM 默认横屏且锁定横屏、无法调整；
- 平台评审/商店分发以横屏为默认预期；
- 3D 探索场景需要更宽的横向视野（如多人竞技类）。

横屏方案下：Seedance 视频改生成 16:9；竖屏手机播放时上下黑边（或视频中心裁剪，裁掉关键表情，风险高，不推荐）；分享卡改 16:9 横版（传播力弱于竖版）。

### 方案 B 回退预案（提前备好，避免临时切换）

- 8/22 前若确认无法锁定竖屏：13 段视频 + 回目卡 + 分享卡 + 预告片全部改 16:9。
- 提前备好 16:9 版提示词与验收口径。
- 该切换需占 8/23–8/26 一个半天。

## 4. 方案对比

| 方案 | 开发量 | 演出效果 | 传播力 | PC 体验 | 风险 |
|------|--------|----------|--------|---------|------|
| A 竖屏 + 缩放居中 | 低（一套布局） | 好（视频全屏零裁切） | 强（竖版分享） | 中（居中+环境背景） | 低 |
| B 横屏 + 双版本视频 | 中（一套布局） | 好（宽视野） | 中（横版分享） | 好 | 中（视频双版本/裁剪） |
| C 真双布局（横竖各一套） | 高（两套 UI + 测试） | 最好 | 强 | 好 | 高（赛程风险大） |

**建议**：选 A；8/19 验证 TTM 能力后，若必须横屏则退回 B；不做 C。

## 5. 竖屏布局分配（方案 A）

### 层级结构（自下而上）

1. **环境背景层**：全屏，覆盖非 9:16 区域的空白（同场景放大模糊/水墨装饰）。
2. **3D 场景层**：全屏 9:16 逻辑区。
3. **演出层**：Seedance 视频全屏 9:16，字幕叠在下方。
4. **UI 层**（urhox-libs/UI）：

### UI 分区（1080×1920 逻辑坐标）

| 区域 | 位置 | 内容 |
|------|------|------|
| 顶部左侧 | 左上角，安全区内 | 任务提示（如"收集桃花 x/5"） |
| 顶部右侧 | 右上角，安全区内 | 暂停 / 旅人札记按钮 |
| 中部 | 全屏 | 演出视频、场景、章回体章节卡 |
| 底部字幕区 | 下方约 1/3 内居中 | 对话/旁白字幕 |
| 底部选项区 | 最下方安全区内 | 对话选项 2~3 个纵向排列，按钮高度 ≥ 常用触摸目标（约 88 逻辑 px） |
| 全屏层 | 章节切换 | 回目卡（9:16）+ 朱红印章 |

### 安全区处理

- 顶部避开刘海/状态栏、底部避开手势条：UI 关键元素（选项、字幕）整体上移安全边距。
- 若引擎无 safe-area API，采用固定内边距（顶部约 100 逻辑 px、底部约 80 逻辑 px）+ 可在配置中调整，真机验证后定稿。

### 字号规范（按逻辑分辨率 1080×1920）

| 层级 | 用途 | 最小字号 |
|------|------|----------|
| 标题 | 回目卡标题、结局标题、章节名 | ≥ 44px（始终大于正文） |
| 正文 | 对话正文、说明文字、任务提示 | ≥ 36px |
| 字幕 | 演出字幕 / 旁白 | ≥ 40px |
| 辅助/按钮 | 按钮文字、标签、角标 | ≥ 32px |

### 交互映射（InputManager 抽象层统一）

| 动作 | 移动端触屏 | PC 键鼠 |
|------|-----------|---------|
| 移动 | 虚拟摇杆为主、点击地面为辅（两者都实现、都进引导） | WASD / 方向键 |
| 交互/对话 | 点按选项 | 鼠标点击 / 空格 / E |
| 打开札记/暂停 | 右上角按钮 | Esc / 鼠标点击 |
| 跳过演出 | 长按或跳过按钮 | 空格 |

## 6. 素材方向统一（竖屏）

- Seedance 视频：全部按 9:16 竖版生成（S1~S9，含结局）。
- 章回体回目卡：9:16 竖版（更新《10-素材清单》原 16:9 设定）。
- 结局分享卡：9:16 竖版（已是）。
- 商店页预告片：9:16 竖版短视频；商店头图/封面按官方尺寸要求单独出图。
- 角色定妆图：以全身像为主（4 张写实定妆图，Seedance 图生视频底图），特写镜头由全身图裁切，不再强制全身/半身各一版（与《10》《11》一致）。
