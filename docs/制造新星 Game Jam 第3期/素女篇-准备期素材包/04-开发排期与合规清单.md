## 官方流程（参考"制造新星 GameJam"往期流程，以本期通知为准）

1. **提交报名**：关注本期报名开放时间，提前完成报名（无论是否已有 TapTap 制造资格都需报名）。
2. **确认报名成功**：官方站内信通知；无资格用户将获得活动定制资格（初始 3,000 Token，不每日恢复，用于创建项目）。
3. **创建项目**：创作期开始（8/19）后，用 TapTap 制造**新建**参赛项目。
4. **绑定活动**：用该项目绑定本期 Game Jam，领取活动专用 100,000 Token 积分（仅限该绑定项目内使用，优先消耗）。
5. **创作发布**：9/8 23:59 前发布上线。

> ⚠️ 每个账号只能绑定一个符合规则的新项目；**绑定后不可改绑、不可取消**。
> ⚠️ 活动积分滥用（用于非绑定项目等）可能被取消资格并追回奖励。

3. 若担心"创作启动前已制作完成"的判定，最终视频资产与项目组装统一放在 8/19 之后执行；准备期只做提示词与风格测试。
4. 发布时务必选择本期 Game Jam 活动绑定，并确认作品状态为"已上线"。
5. 作品需具备完整、可玩的基础体验——本方案 8~15 分钟、三结局、无卡关设计，满足该要求。
6. **不引导好评、不刷数据**：评价引导保持中性（"欢迎分享你的体验与结局"），违规行为一经核实取消资格。
7. **广告激励金仅限推广该获奖作品**，不可提现、不可转让；现金奖励税前结算给发布账号，团队分配需自行书面约定。
8. **体量兜底预案**：若 8/27 后评估超预算——砍洛水阴山自由探索、改为单场景对话 + 试炼，保底双结局（重逢/放手），与设计总览一致。
