## Radius Tokens

Usage: `UI.Theme.Radius("name")` -> `number`

| Token | Value | Usage |
|-------|-------|-------|
| `sm` | 6 | TextField, dropdown trigger |
| `md` | 10 | Default controls, alerts, toast, popover, accordion |
| `lg` | 16 | Cards |
| `xl` | 20 | Modal, drawer |
| `full` | 9999 | Pill shape — buttons, badges, chips, toggle, slider |

**Pill shape:** `borderRadius = 9999` is safe for buttons. NanoVG auto-clamps to `min(w, h) / 2`, producing correct pill ends.

**Standard interactive control radius:** `borderRadius = 10` (componentDefaults). Cards use 16, modals/drawers use 20.

## Font Sizes

Usage: `UI.Theme.FontSizeOf("name")` -> `number` (returns converted render value)

| Design px | pt Value | Usage |
|-----------|----------|-------|
| 28px | 21pt | H1 display headings |
| 22px | 16.5pt | H2 section titles |
| 18px | 13.5pt | H3 subtitles, button text |
| 14px | 10.5pt | Body text |
| 13px | 9.75pt | Component text (TextField, List items) |
| 12px | 9pt | Small text, badges, captions |
| 10px | 7.5pt | Caption, auxiliary text |

**Custom font size conversion:** `pt = px * 0.75`
