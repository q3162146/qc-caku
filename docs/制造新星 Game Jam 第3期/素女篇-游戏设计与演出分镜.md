# 《桃素洛无幽·素女篇》游戏设计与 Seedance 演出分镜

> 适用赛事：TapTap 制造 × Seedance 视频模型主题赛
> 版本：v1.0（2026-08-09）
> 定位：可直接在 TapTap 制造中开工的单机短篇互动叙事游戏

---

## 1. 作品定位

| 项目 | 设定 |
|------|------|
| 游戏名（暂定） | 《桃素洛无幽·素女篇》/ 副标题《无涕桃》 |
| 类型 | 短篇剧情冒险（探索 + 记忆试炼 + 互动对话） |
| 时长 | 8~15 分钟，三结局，可重复游玩 |
| 平台 | TapTap 制造（单机模式） |
| 核心体验 | 让玩家"走进"一个关于等待、遗忘与重逢的传说 |

**一句话卖点**：玩家扮演无名旅人，在朝阳之谷听守桃老人讲完素女十二年的守望，又在洛水阴山遇见失忆流泪的无面鬼，通过六艺试炼一点点捡回他的记忆，最终把五朵桃花送回无涕桃——春风再起时，两人得以重逢。

## 2. 与比赛主题的契合点

比赛主题的核心是 Seedance 的三个能力：**让角色开口、让场景动起来、让情绪真正发生**。素女篇文本天然为这三者而写：

| Seedance 能力 | 素女篇中的落点 |
|--------------|---------------|
| 角色开口 | 无幽临别之言"待春风至，桃花香的那一天必然重逢"；无面鬼的哀号与追忆诗句；守桃老人讲述传说 |
| 场景动起来 | 漫山碧叶桃花四季不落 → 春夜一夜飘零；风雪雨霜的时间流逝；洛水阴山的异域小镇；最终桃花重新绽放 |
| 情绪真正发生 | 守望的坚定 → 离别的遗憾 → 遗忘的哀伤 → 追忆的清明 → 重逢的释然，完整情绪弧线，且结尾温暖不煽情 |

设计原则：**Seedance 视频负责"演出"，游戏负责"选择与参与"**，两者交替推进，避免做成纯视频播放器。

对照官方评审维度（演出沉浸感 / 抉择深度 / 叙事创新性）：

| 评审维度 | 落点 |
|----------|------|
| 演出沉浸感 | 13 段 Seedance 演出 + 配音/字幕/环境音分层 + 桃花粒子 + 选择即时反馈 |
| 抉择深度 | 信念系统：无面鬼对话抉择 + 5 段记忆印证（无对错解读）+ 终局抉择（两行动），三结局 |
| 叙事创新性 | 玩家成为传说的共同讲述者；记忆即叙事；双层时间结构；元叙事闭环 |

> 详细规格见《素女篇-准备期素材包/05-评审维度强化-抉择系统与叙事创新.md》。

**传统文化融入**：以"章回体说书"为叙事框架（守桃老人即说书人），五朵桃花对应五行方位，六艺记忆印证嵌入礼乐射御书数文化意象，关键画面叠加诗词题跋（《诗经·桃夭》《人面桃花》），并用节气与地支丈量十二载守望；另设"旅人札记"轻量图鉴，触达文化点自动解锁，不设文化考题。详细规格见《素女篇-准备期素材包/06-中国传统文化元素融入方案.md》。

## 3. 核心玩法循环

```
开场演出（朝阳谷口全景）
        │
        ▼
自由探索朝阳之谷 ──► 与守桃老人对话，听传说，接任务
        │
        ├─► 收集 5 朵桃花（分布在谷内故事点）
        │
        ▼
前往洛水阴山，遇见无面鬼
        │
        ▼
记忆印证 ×5：无对错解读，播放 Seedance 记忆影像并选择信念方向
        │
        ▼
返回朝阳之谷，将 5 朵桃花献于无涕桃
        │
        ▼
最终演出 → 三结局（重逢 / 放手 / 传说）
        │
        ▼
制作名单 + 回到标题
```

**节奏**：演出 30~60 秒 → 探索/对话 2~3 分钟 → 演出 30 秒 → 试炼 3~4 分钟 → 终局演出 1 分钟。全程 8~15 分钟。

## 4. 剧情结构与情绪弧线

采用"双线并置、一线收束"结构：

- **素女线（现在·朝阳之谷）**：旅人听守桃老人讲述素女十二年守望的故事，收集五朵桃花——每一朵都对应素女等待中的一个细节（谷口、桃树下、井边、望夫崖、守桃老人屋）。
- **无幽线（现在·洛水阴山）**：旅人遇见无面鬼。他没有记忆也没有感情，却总在流泪。玩家给他水、陪他发呆、与他说话，通过六艺试炼逐段唤醒记忆。
- **收束（结局）**：记忆碎片拼出完整往事——无幽正是素女等待的丈夫。献花于无涕桃，春风起，两人重逢。

情绪曲线：

```
宁静(开篇) → 怅惘(传说) → 沉重(十二载守望) → 哀伤(无面鬼)
→ 清明(记忆恢复) → 释然与温暖(重逢)
```

## 5. 场景设计（3 个）

| 场景 | 氛围 | 内容 | 天气/动态 |
|------|------|------|----------|
| 朝阳谷口 | 明亮、桃花漫山 | 出生点、素女守望处、无涕桃 | 花瓣飘落、微风 |
| 谷内桃林 | 清幽 | 守桃老人屋、井、桃树群、望夫崖 | 光斑、溪水 |
| 洛水阴山 | 异域、雾霭 | 小镇、无面鬼处、矿场小路 | 残阳、风沙/雾 |

世界单位采用米、Y 轴向上（引擎规范），角色尺度约 1.6~1.8 米，模型尺寸用 boundingBox 动态获取。

## 7. 互动与轻玩法细节

### 7.1 探索与对话
- 玩家可在场景中走动、与 NPC 对话（守桃老人、无面鬼、小镇路人）。
- 对话系统提供 2~3 个选项，每个关键选项都会向"信念系统"加分（重逢/成全/传说），并在结局回声，不阻断流程（降低开发与体验风险）。
- 示例选项（对无面鬼）：「递上一碗山泉」（成全+1）「默默陪他坐着」（传说+1）「轻声唤：无幽」（重逢+1）——不同选项触发不同小演出与台词，并影响结局走向。

### 7.2 五朵桃花收集
- 分布于朝阳之谷 5 个故事点：谷口、桃树下、望夫崖、井边、守桃老人屋（顺序见《06》§2 五行方位）。
- 每朵桃花拾取时触发 1~2 句素女视角的内心独白（配音），强化"等待"主题。
- 任务提示由 UI 系统（urhox-libs/UI）呈现：已收集 x/5。

### 7.3 六艺 · 记忆印证（无幽记忆恢复）
- 共 5 段，对应礼、乐、射、御、书（数并入书/药方题，控制体量）。
- 每段 Seedance 记忆影像播放后，玩家选择**自己相信的解读**（无对错，只有方向），例如：
  - 礼：素女为什么没有拦他？——她懂他的执着（重逢）／她怕拦了就走不成了（成全）／她只是等故事发生（传说）
  - 乐：那曲琴声听成了什么？——等你回来／一路平安／桃花落在水面上的声音
  - 射：那支箭穿过桃花枝，准还是不准？——心无旁骛／偏了半寸／花落才重要
  - 御：回望谷口时看见什么？——素衣身影／桃花／空谷
  - 书/数：那味药是"当归"还是"不归"？——当归／不归／没写完的话
- 每轮选择向对应信念轴加分，追加 1~2 句匹配旁白，让玩家感到"故事随我的解读在变化"。
- 玩家不是在答考题，而是在**重写记忆、讲述自己的版本**（对应"记忆即叙事"的创新点）。

### 7.4 献花与结局
- 集齐 5 朵桃花 + 完成 5 段记忆印证后，返回朝阳之谷面对无涕桃，进入**终局抉择（两行动、三结局）**：
  - **献花于无涕桃**（始终可选）：重逢值最高 → S7 重逢结局；成全值最高 → S8 放手结局。
  - **摘下无涕桃**（传说值≥3 或二周目解锁）：S9 传说结局（元叙事）。
- 终局画面回放玩家此前的一个关键选择瞬间（递水/唤名/陪坐），强化"选择被记住"。
- 触发结局视频 → 制作名单 → 回到标题；标题界面显示结局收集（0/3 朵桃花），可重玩补全全部结局。
- **完整故事回看**：标题界面提供"故事回看"入口——通关一次即解锁主线完整回看（S1~S6 按章回体顺序播放）；集齐三结局后解锁完整版（含 S7/S8/S9 与结局分支说明）。只想看故事的玩家不必重复游玩，做选择的玩家仍可多周目收集。

### 7.5 中国传统文化融入（摘要）

- 叙事框架：章回体章节卡（楔子～尾声）+ 说书转场"欲知后事如何，且听下回分解"。
- 收集机制：五朵桃花 = 五行（木火土金水）+ 方位（东西南北中，木东火南金西水北土中）+ 季节，集齐点亮五枚印章。
- 文化锚点：六艺记忆印证各嵌一个意象（揖礼、古琴/知音、射礼、六艺之御、河图洛书/算筹），由札记补充出处。
- 文学题跋：桃夭、人面桃花、望夫崖诗句等，以书法体字幕叠加在演出画面上。
- 时间文化：S3 守望蒙太奇以二十四节气为时间标尺，"十二年 = 一轮生肖"。
- 图鉴系统：旅人札记 24+1 条，触达即解锁，暂停菜单翻阅；全收集点亮"博古通今"印章。
- 预算分层：章回体、五行桃花、文化台词、诗词题跋为必做；札记图鉴、节气字幕、器物细节为可选。

## 8. 技术落地要点（TapTap 制造 / UrhoX 规范）

- 单机模式：项目入口 `scripts/main.lua`，启动时读取 `.project/settings.json` 的 `multiplayer.enabled`（本项目预期为 false）。
- 模块划分（预估总量 <1000 行，可扁平或分组）：
  - `main.lua`：初始化与路由
  - `config/`：PlayerData / GameData 数据结构、段落表 Chapters、题目表、结局判定
  - `flow/`：流程控制器（只做"当前在哪一段、完成后去哪一段"，读段落表推进）
  - `game/`：探索、对话、收集、试炼逻辑（玩法模块只返回统一完成结果，不跳段）
  - `media/`：视频播放器管理（剧情视频存位置恢复 / 循环背景销毁重建、预加载分层、资源释放）
  - `ui/`：对话、选项、字幕、任务提示（统一用 urhox-libs/UI，自定义特效才用 raw NanoVG）
- **段落化架构（2026-08-19 吸收官方案例新增）**：全部剧情按段落表数据驱动；玩法模块统一返回 `{ done, beliefDelta, unlocked, flag, next }`，流程控制器只认 `done`；新增玩法不改流程推进。详见《21-互动影游双案例应用清单》。
- 数据安全：PlayerData 固定字段含 `schemaVersion`（版本化迁移）、`flags`（跨段落标记）、`mediaPos`（当前段落/视频/断点序号/精确时间，读档恢复契约）；载入存档做类型检查与默认值兜底，防老存档缺字段崩溃。
- 输入：使用 urhox-libs/Input/InputManager 抽象层；事件用 KEY_* / MOUSEB_* 枚举，严禁数字常量。
- 规则与表现分离：演出播放、动画、音频函数内不修改游戏数据；流程为 输入 → 规则判断 → 数据变化 → 表现。
- 资源路径：全部经 `cache:GetResource("...", "Videos/xxx")` 等引擎相对路径引用，从资源根下一级开始，不加 `assets/` 前缀，无任何本地绝对路径。
- 3D 模型尺度用 boundingBox 动态获取；程序化材质只用 PBRNoTexture 系列 technique。
- 日志用 `print("[模块名] 消息")`，开发期多打、稳定后清理。
- 屏幕适配：**以移动端竖屏 9:16 为主**（逻辑分辨率 1080×1920），固定逻辑分辨率 + 等比缩放 + 居中视口 + 环境背景层，覆盖竖屏手机、横屏手机、平板与 PC；Seedance 视频与分享卡统一 9:16。详细方案见《素女篇-准备期素材包/13-屏幕方向与UI适配方案.md》。

## 11. 商业化与运营要点

- **首发定位：非商业化**（免费、无广告、无内购），保住演出沉浸感与评分，同时满足"非商业化额外资源支持"条件；商业化能力作为预留开关，后续按需解锁。
- **30 天达标**（热度≥3000 / 新增评价≥20 / 评分≥7.0）：结局分享卡（三结局 × 题跋诗句 + 国风 Q 版角色贴纸，带游戏名与 TapTap 链接）做裂变；Seedance 名场面剪 15~30 秒短视频；商店页用 S1 开场图与情感化标题；结局后只做中性评价引导，严禁引导好评。
- **回访设计**：三结局收集（0/3 桃花）、二周目隐藏内容、旅人札记全收集、章节速通模式。
- **运营节奏**：上线后每月一次小更新（节气彩蛋/新札记/设定集）保持"有效更新"，持续领取激励金与积分；申请编辑推荐与聚光灯计划。

> 详细方案见《素女篇-准备期素材包/07-商业化与运营方案.md》。
